# Developer CLI Tools

The Prumo CLI (`prumo`) provides an all-in-one executable for project orchestration, execution, and verification.

## Common Commands

- `prumo run`: Execute directives and task plans.
- `prumo goal new`: Create new Goals.
- `prumo goal state`: Transition Goal states (`PLANNED`, `LOCKED`, `COMPLETED`).
- `prumo compile`: Compile harness adapters for Claude Code, Antigravity, Cursor, and Codex.
- `prumo doctor`: Run full repository diagnostics.
- `prumo docs audit`: Verify documentation authority, version consistency, and links.
