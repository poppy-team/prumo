# Governance & Authority

Prumo maintains strict knowledge hierarchy and drift prevention:

1. **Canonical Repository**: Specifications, ADRs, schemas, code, and tests.
2. **Approved Living Book (Notion)**: Architecture and design decisions awaiting promotion.
3. **Agent Inference**: Bounded, evidence-backed propositions.

## Lean Progressive Context (LPC)

Context is treated as an expensive, scarce resource. Prumo delivers strictly the smallest sufficient context needed for each task, avoiding token waste and hallucinations.
