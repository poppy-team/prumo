# Connectors & Harness Adapters

Prumo adopts a provider-agnostic architecture. No execution environment or LLM vendor has direct authority over the project's canonical truth.

---

## Global Connectors vs. Project Adapters

It is essential to distinguish the two levels of Prumo integration:

1. **Global Connector (`prumo connector ...`)**: 
   Operates on your computer (`~/.prumo/connectors/`). It manages installation, the tool's availability status on the `$PATH`, and the capabilities negotiated with that agent's executable (e.g. Claude Code, OpenCode CLI, Antigravity).
2. **Project Adapter (`prumo compile --target ...`)**: 
   Operates on the active repository (`./`). It surgically generates or injects context rules, skills, and instructions that the agent will read when opened in this folder (e.g. `CLAUDE.md`, `.gemini/`, `.opencode/`, `.cursorrules`).

---

## Managing Connectors (`prumo connector`)

### List Available and Registered Connectors
```bash
prumo connector list
```

### Inspect a Connector's Status and Health
```bash
prumo connector status claude
prumo connector status opencode
prumo connector status antigravity
```
The command reports:
- Version and enforcement model (strict vs standard).
- Whether it is installed in `~/.prumo/connectors/`.
- Whether the tool's binary was detected on your `$PATH`.
- The complete list of supported capabilities (advise, restrict_tools, session_hooks, etc.).

### Install a Connector Globally
```bash
prumo connector install opencode
prumo connector install claude-code
```

## Compiling Project Adapters (`prumo compile`)

To sync your active project's context rules with your preferred agents:

```bash
# Compile adapters for all supported connectors
prumo compile --all

# Sync specific rules for Claude Code (generates CLAUDE.md)
prumo compile --target claude-code

# Sync rules for Google Antigravity (generates .gemini/)
prumo compile --target antigravity

# Sync for Cursor (generates .cursorrules)
prumo compile --target cursor
```

### Managed Regions (`doccompile`)

When Prumo updates an instructions file (such as `CLAUDE.md` or `AGENTS.md`), it uses delimiter markers:

```markdown
<!-- prumo:begin agents-core -->
<!-- prumo:generated adapter=agents-md scope=root fingerprint=... sources=... -->
- Instructions automatically generated by the Prumo compiler...
<!-- prumo:end agents-core -->
```

Any text outside these markers belongs to the project's developers and is fully preserved during compilations, installations, or uninstallations.
