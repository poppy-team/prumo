# Prumo Architecture

Prumo is built on the principle of **Git-native durable truth**:

1. **Repository Authority**: Markdown, JSON Schemas, and Git history own project truth.
2. **Provider Neutrality**: No single LLM provider or harness vendor is mandatory.
3. **Pure Go Implementation**: Zero external script interpreter or virtualenv dependencies.
4. **Rust Native Viewer**: Fast interactive workspace visualizer (`prumo-viewer`).
