# Prumo Harness & Autonomous Execution

The **Prumo Harness** is the headless execution engine of Prumo. It translates compiled engineering intent into sandboxed, verified actions.

## Key Capabilities

- **Tool Gateway & ACI**: Safe process execution, bounded outputs, and AST-level inspections.
- **Task DAG Execution**: Automated dependency ordering and gate evaluation.
- **Model Portfolio & Routing**: Intelligent provider-neutral LLM routing with budget governance.
- **Session Resumption & Daemons**: Background execution with atomic replay logs.
