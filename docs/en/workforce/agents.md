# Specialist Agent Catalog (39 Agents)

Prumo ships with **39 pre-configured autonomous agents**, designed to act with surgical focus and clear boundaries of responsibility and authority.

## Division by Domain Area

### 1. Systems Engineering, Compilers & Runtime

| Agent | Role | Main Responsibility |
|---|---|---|
| **`compiler-engineer`** | Compiler Engineer | Lexical frontend, syntactic parser, AST, static type checking, and bytecode/Wasm emitters. |
| **`systems-architect`** | Systems Architect | Low-level architecture, concurrency, memory allocation, and hardware performance patterns. |
| **`engine-engineer`** | Game Engine Engineer | Deterministic execution loops, physics, entity management, and virtual time. |
| **`renderer-engineer`** | Rendering Engineer | Graphics pipelines, shaders, software/hardware drawing backends, and canvas. |
| **`debugger`** | Debugging Engineer | Panic isolation, core dump analysis, profiling, and memory leak elimination. |
| **`performance-agent`** | Optimization Agent | Comparative benchmarks, CPU/memory profiling, and mitigation of performance regressions. |
| **`scientific-computing-agent`** | Scientific Computing | Numerical algorithms, floating-point precision, matrices, and physical simulations. |

### 2. Software Architecture, Backend & Platform

| Agent | Role | Main Responsibility |
|---|---|---|
| **`architect`** | Software Architect | Macro cohesion, DDD, preservation of boundaries between modules, and ADR conformance. |
| **`backend-engineer`** | Backend Engineer | APIs, gRPC/REST contracts, domain services, and transactional data integrity. |
| **`database-engineer`** | Database Engineer | Relational modeling, deterministic migrations, indexes, and ACID transactions. |
| **`networking-engineer`** | Networking Engineer | TCP/UDP protocols, WebSockets, binary serialization, and network partition tolerance. |
| **`devops-engineer`** | Infrastructure & CI Engineer | Automation pipelines, hermetic builds, container packaging, and safe deploys. |
| **`editor-engineer`** | IDE & Editor Engineer | LSP protocol, syntax highlighting, IDE plugins, and editing environment ergonomics. |

### 3. UI/UX, Design Systems, Vectors & Motion

| Agent | Role | Main Responsibility |
|---|---|---|
| **`design-system-engineer`** | Design System Engineer | Design token specification, theme architecture, color semantics, and CSS variables. |
| **`ui-component-engineer`** | UI Component Engineer | Implementation of modular, accessible, and reactive interface components. |
| **`ux-architect`** | UX Architect | User flows, information architecture, accessibility (WCAG AAA), and usability. |
| **`design-researcher`** | Design Researcher | Market benchmarking, heuristic testing, and scientific validation of visual patterns. |
| **`svg-artist`** | SVG & Icon Artist | Mathematical creation of vector art, scalable SVG illustrations, and icon families. |
| **`motion-designer`** | Animation & Motion Designer | Fluid microinteractions, physical easing curves, and performant screen transitions. |
| **`accessibility-reviewer`** | Accessibility Reviewer | Contrast audits, screen reader support, keyboard navigation, and ARIA semantics. |

### 5. Quality, Testing, Auditing & Security

| Agent | Role | Main Responsibility |
|---|---|---|

### 6. Orchestration, Triage & Exploration

| Agent | Role | Main Responsibility |
|---|---|---|

| **`prototyper`** | Rapid Prototyper | Agile creation of proofs of concept (PoCs) and experimental validation of technical hypotheses. |
