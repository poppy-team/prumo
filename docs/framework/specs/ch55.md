# 55 — Observability Plane, Run Explainability e Incident Bundles

> Authority: canonical specification.
> Logical ID: PART1-CH-55
> Source: Notion Living Book (3d59bb7d023f81748fe3c10c243b9e97)
> Status: Especificação de engenharia do Framework (Capítulo 55).


## Objetivo

Tornar o harness auditável sem persistir chain-of-thought.

## Run telemetry

Timeline estruturada com events, model calls, token/cost usage, context manifests, skills/workforce selecionados, tool calls, policy decisions, environment, evidence, retries, failures e checkpoints.

## Explainability commands

```bash
atlas run show <id>
atlas explain context <id>
atlas explain skills <id>
atlas explain workforce <id>
atlas explain model <id>
atlas explain tools <id>
```

Explicações apontam regras, scores/evals e inputs objetivos usados pelo resolver.

## Storage

Local-first em SQLite/artefatos derivados. Git recebe apenas história/evidence que o protocolo definir como durável.

## OpenTelemetry

Planejar exporter OTLP opcional para equipes; core local não depende dele.

## Incident Bundle

`atlas debug bundle <run>` produz bundle sanitizado com versões, hashes de config, connector/model IDs, environment fingerprint, eventos e falhas. Secrets e conteúdo classificado são redigidos.

## SLOs internos futuros

Run success, resume success, policy-denial correctness, mean unnecessary tool calls, context efficiency, provider error rate e automation failure rate.

## Privacy

Telemetry respeita data classification; prompts/outputs completos não são registrados por padrão.

# Amendment 2026-09-21 — Evidence Observability

[84 — Total Assurance Constitution: Gauntlet Loop, Evidence e Anti-False-Green](../../quality/gauntlet-84.md) exige que Observability relacione run events a acceptance/evidence/gates sem gravar raciocínio privado. Acrescentar stale-evidence explanation, false-green diagnostics, resource/performance traces, cancellation/recovery timeline e evidence provenance. Incident Bundle deve tornar reproduzível o que aconteceu e quais gates foram enganados ou corretamente acionados.
