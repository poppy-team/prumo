Physics/collision precisa de um profile próprio porque muitos defeitos só aparecem com combinações espaciais, altas velocidades, timestep variável e contato persistente.

# Skill family

- `game-physics-design`
- `collision-design`
- `character-controller`
- `movement-feel`
- `physics-debugging`
- `physics-testing`

# Collision suites

Cobrir ao menos:

- overlap enter/stay/exit;
- ray/sweep/shape cast;
- collision masks/layers;
- trigger vs solid;
- high-speed tunneling;
- continuous collision quando disponível;
- corner/edge contacts;
- stacked bodies;
- sleeping/waking;
- moving platforms;
- one-way surfaces;
- slopes;
- stairs/steps;
- ledges;
- ceilings;
- narrow passages;
- dynamic obstacles;
- respawn/teleport;
- scale extremes suportados.

# Property-based geometry tests

Gerar posições/velocidades/ângulos dentro de domains válidos e verificar propriedades como:

- nenhuma posição final contém NaN/Inf;
- objetos não atravessam barreiras contínuas quando CCD é requerido;
- grounding não alterna de forma espúria além do tolerance esperado;
- penetration resolution converge dentro do budget;
- contatos respeitam layers/masks;
- character controller não ganha energia/velocidade sem fonte permitida.

# Character controller contract

Documentar e testar explicitamente:

- acceleration/deceleration;
- maximum speed;
- air control;
- jump impulse/height;
- coyote time;
- input buffering;
- slope limit;
- step height;
- gravity/fall speed;
- friction/traction;
- moving platform inheritance;
- root motion relationship;
- collision response.

# Determinism

Physics engines podem divergir por plataforma/precision. O Atlas deve registrar:

- expected deterministic scope;
- tolerances numéricas;
- reference platform;
- fixed timestep policy;
- replay compatibility.

# Visual debug evidence

Quando um teste falhar, preferir artifacts reproduzíveis:

- collider wireframes;
- contact normals;
- swept volume;
- trajectory;
- frame/tick number;
- seed;
- actor transforms;
- short replay.

# Regression scenarios

Cada bug real de física/collision deve virar cenário mínimo reproduzível, não somente screenshot ou descrição textual.
