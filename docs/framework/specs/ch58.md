## Migration Engine

Atlas precisa migrar seus próprios schemas/configs por anos, não apenas Python → Go.

Contrato de migration: id, from/to version, preconditions, backup strategy, transform, post-validation, reversibility/rollback e affected canonical artifacts.

## Segurança

`atlas migrate --dry-run` mostra mudanças. Backup/checkpoint antes de migrations materialmente destrutivas. Migrations são determinísticas sempre que possível e testadas por fixtures de versões antigas.

## Journal

Registrar migrations aplicadas, version, timestamp lógico, hashes e resultado para impedir dupla aplicação e facilitar diagnostics.

## Unified Review Queue

Unificar propostas que exigem decisão humana:

- ExperienceProposal;
- SkillProposal;
- Documentation contradiction/patch;
- Security waiver;
- Migration proposal;
- publication draft/approval quando configurado.

CLI alvo:

```bash
atlas review
atlas review show <id>
atlas review accept <id>
atlas review reject <id>
atlas review defer <id>
```

Cada review item contém diff/summary, evidence, risk, source, expiry/reconsideration conditions e downstream impact.

## Rule

Aprovação humana é um tipo de evidence/event, não uma alteração invisível de estado.
