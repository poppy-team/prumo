# 16 — Gap Analysis v0.3 → v0.4 e Correções Necessárias

> Authority: canonical specification.
> Logical ID: PART1-CH-16
> Source: Notion Living Book (3d59bb7d023f8132b4b4c1d433e36267)
> Status: Especificação de engenharia do Framework (Capítulo 16).


O v0.3 possui core Python em `src/project_atlas`, `pyproject.toml`, scripts Python no root, 24 JSON Schemas, Goals v2, workforce packages, LPC/PCA, compilers para harnesses, doctor/explain e conformance determinística.

## Classificação de componentes atuais

### Permanecem conceitualmente canônicos

- repository as source of truth;
- provider-agnosticism;
- Markdown/JSON/JSON Schema;
- Goal v2 locks/amendments;
- Plans/Tasks/Evidence/Gates/Events;
- workforce resolver;
- skills/agents/recipes;
- LPC/PCA;
- doctor/explain;
- deterministic conformance;
- trust hierarchy.

### Reimplementar em Go

- CLI;
- project/config loader;
- schema validator;
- Goal lifecycle;
- compiler/resolver;
- diagnostics;
- state/event operations;
- scaffolding;
- migrations que ainda forem permanentes.

### Deprecar

- dependência Python para uso normal;
- `pip install -e .` como caminho oficial de instalação;
- OpenCode tratado apenas como generic adapter;
- documentação baseada apenas em taxonomia de pastas sem contracts de profundidade;
- reliance em prompt para enforcement de invariantes que podem ser verificadas determinísticamente.

### Avaliar/triagem

- `fix_schemas.py`;
- `write_docs.py`;
- targets de integração pouco usados;
- qualquer generated artifact cujo ownership não esteja marcado.

## Correções arquiteturais

1. Separar domínio de protocolo de CLI e storage.
2. Criar machine API versionada para harnesses.
3. Criar Connector Contract antes de multiplicar adapters.
4. Tornar install/uninstall parte do produto, não instrução manual.
5. Formalizar documentation readiness.
6. Formalizar conversation decision authority.
7. Diferenciar canonical/historical/episodic/experiential memory.
8. Adicionar typed knowledge relations.
9. Adicionar cleanup/ownership manifests.
10. Testar connector behavior com contract suite.
