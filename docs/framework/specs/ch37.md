Gamefeel é uma propriedade de experiência, não apenas correctness. O Atlas deve decompor a experiência em parâmetros mensuráveis sem fingir que métricas substituem avaliação humana.

# Research baseline

A survey de Pichlmair e Johansen organiza game feel em três grandes intenções: **physicality/tuning**, **amplification/juicing** e **support/streamlining**. Essa taxonomia é útil para transformar discussões vagas em documentação e testes orientados por propriedades.

Fonte: [https://doi.org/10.1109/TG.2021.3072241](https://doi.org/10.1109/TG.2021.3072241)

# Game Feel Specification

Cada mecânica central pode declarar:

- player intention;
- input mapping;
- input buffer/window;
- response latency target;
- acceleration/easing;
- animation anticipation/follow-through;
- camera response;
- hit stop / freeze frames;
- screen shake;
- particles/VFX;
- sound/haptics;
- aim assist / snapping;
- coyote time / forgiveness;
- cancellation rules;
- recovery time;
- visual/audio confirmation.

# Objective tests

Automatizar o que é objetivamente observável:

- input-to-action ticks/ms;
- frame pacing;
- input buffering windows;
- jump arc/distance;
- acceleration curves;
- camera overshoot;
- FOV changes;
- recoil/reset timing;
- attack startup/active/recovery frames;
- hit detection windows;
- animation-event alignment;
- haptic/audio event firing.

# Subjective tests

Gamefeel final deve possuir structured playtest com hipóteses e escalas claras:

- responsiveness;
- perceived control;
- readability;
- weight;
- impact;
- frustration;
- mastery;
- motion comfort;
- feedback clarity.

Não transformar percepção humana em gate automático sem validação empírica.

# Ablation playtests

Uma técnica valiosa para tuning:

- remover VFX;
- remover áudio;
- remover camera shake;
- remover aim assist;
- alterar acceleration;
- comparar variantes A/B.

Isso ajuda a identificar qual componente realmente produz a sensação desejada.

# Accessibility

Gamefeel e accessibility não são antagonistas. Skills devem verificar opções como:

- remapping;
- hold/toggle;
- deadzone;
- sensitivity;
- camera shake control;
- motion blur control;
- haptics intensity;
- aim assistance;
- timing forgiveness quando cabível.
