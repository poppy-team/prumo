# Game design

## MDA

Hunicke, LeBlanc e Zubek — *MDA: A Formal Approach to Game Design and Game Research*.

Uso Atlas: ligar Mechanics → Dynamics → intended Aesthetics como lente de análise do GDD.

[https://aaai.org/papers/ws04-04-001-mda-a-formal-approach-to-game-design-and-game-research/](https://aaai.org/papers/ws04-04-001-mda-a-formal-approach-to-game-design-and-game-research/)

# Game feel

Pichlmair & Johansen — *Designing Game Feel: A Survey*, IEEE Transactions on Games. Survey de mais de 200 fontes; organiza gamefeel em physicality/tuning, amplification/juicing e support/streamlining.

[https://doi.org/10.1109/TG.2021.3072241](https://doi.org/10.1109/TG.2021.3072241)

# Automated playtesting

Le Pelletier de Woillemont, Labory & Corruble — RL baseado em playstyles humanos para automated playtesting.

[https://ojs.aaai.org/index.php/AIIDE/article/view/21958](https://ojs.aaai.org/index.php/AIIDE/article/view/21958)

Gutiérrez-Sánchez et al. — RL para avaliar impacto de mudanças em AI/behavior trees sobre game design já testado.

[https://ojs.aaai.org/index.php/AIIDE/article/view/18885](https://ojs.aaai.org/index.php/AIIDE/article/view/18885)

# Level evaluation

Liapis, Yannakakis & Togelius — avaliação de levels com conceitos quantificáveis de area control, exploration e balance.

[https://ojs.aaai.org/index.php/AIIDE/article/view/12680](https://ojs.aaai.org/index.php/AIIDE/article/view/12680)

Mariño, Reis & Lelis — estudo alerta que métricas computacionais de levels não devem substituir user studies.

[https://ojs.aaai.org/index.php/AIIDE/article/view/12785](https://ojs.aaai.org/index.php/AIIDE/article/view/12785)

# Player modeling / difficulty

Zook & Riedl — temporal player model para dynamic difficulty adjustment, ligando evolução de skill a perceived difficulty.

[https://ojs.aaai.org/index.php/AIIDE/article/view/12504](https://ojs.aaai.org/index.php/AIIDE/article/view/12504)

Isaksen & Nealen — skill, game variants e learning rates com survival analysis; útil para raciocinar sobre difficulty curves e balance.

[https://ojs.aaai.org/index.php/AIIDE/article/view/12846](https://ojs.aaai.org/index.php/AIIDE/article/view/12846)

Shields, Withington & Melcer — expressive-range analysis de DDA para avaliar se directors atendem goals de designer.

[https://ojs.aaai.org/index.php/AIIDE/article/view/36835](https://ojs.aaai.org/index.php/AIIDE/article/view/36835)

# Research rule

Papers e práticas industriais informam nossos defaults; nenhuma técnica é universal. Skills devem explicitar applicability, limitations, evidence level e quando um designer/player humano ainda é o oracle necessário.
