# Bundles

### `bundle:game-core`

Candidatos: game-development, game-architecture, clean-code, game-testing, game-performance-budget.

### `bundle:game-ai`

Game AI architecture + model-specific skills + AI testing/debugging.

### `bundle:game-design`

GDD + systems + balance + level/playtest.

### `bundle:game-tooling`

Tooling + editor UX + assets + project format + GUI testing.

### `bundle:multiplayer-game`

Networking + security + simulation + performance.

Bundles não carregam tudo automaticamente; Ambient Resolver escolhe o subset mínimo.

# Automatic activation

Auto skills recomendadas conforme intenção:

- qualquer code change de game → `clean-code` + `game-testing`;
- performance-sensitive change → `game-performance-budget`;
- physics/movement → physics-testing + gamefeel quando afeta player control;
- AI change → game-ai-testing + game-ai-debugging;
- balance/design tuning → balance-analysis + playtest-design;
- map/level change → level-design + spatial validation;
- multiplayer → network-testing + security-baseline;
- asset/tooling → content-validation + compatibility-awareness.
