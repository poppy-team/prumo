# 13 — Testes, Conformance, Evals e Quality Gates

> Authority: canonical specification.
> Logical ID: PART1-CH-13
> Source: Notion Living Book (3d59bb7d023f814bb4a1f65f29941287)
> Status: Especificação de engenharia do Framework (Capítulo 13).


O Atlas deve testar tanto código Go quanto **comportamento de protocolo e qualidade de orchestration/documentação**.

## Pirâmide

### Unit

Domain rules, parsers, resolvers, risk, applicability, state machines.

### Integration

Filesystem temp dirs, Git repositories, SQLite derived index, connector generation.

### Conformance

Inputs/outputs golden e scenarios determinísticos independentes da implementação.

### Connector Contract Tests

Harness-specific setup, hooks, permissions, cleanup e compatibility.

### End-to-End

Projetos fixture executando init -> plan/adopt -> compile -> validate -> docs -> handoff.

### LLM Evals

Somente onde há comportamento probabilístico: interview quality, decision extraction, docs completeness, retrieval e contradiction suggestions.

## Migration gate

Go não substitui Python até alcançar paridade nos contratos críticos.

## CI recomendada

```
gofmt check
go test ./...
go vet ./...
staticcheck ./...
govulncheck ./...
conformance
schema validation
connector fixtures
```

## Documentation contract tests

Fixtures deliberadamente incompletas devem comprovar que o Atlas distingue missing/partial/ready/not-applicable.

## Adoption fixtures

Criar repositórios de teste com:

- docs boas em layout não Atlas;
- docs duplicadas;
- contradição README vs config;
- projeto sem docs;
- monorepo;
- mixed languages.

## Retrieval benchmark

Perguntas reais com answer pointers conhecidos. Não escolher embeddings por preferência tecnológica.

## Performance budget do próprio Atlas

Definir budgets para:

- startup;
- `doctor` em repositório pequeno/médio/grande;
- `adopt --audit-only`;
- lookup de trace;
- connector compile.

## Determinismo

Quando o output deveria ser determinístico, tests não podem depender de LLM. LLM é usado apenas em camadas explicitamente probabilísticas.
