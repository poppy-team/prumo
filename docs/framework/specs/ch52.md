## Atlas Tool Gateway

Toda ação mediável passa por um gateway lógico:

```
Agent → Tool Gateway → Policy → Permission → Budget → Sandbox → Tool/MCP
```

## Tool descriptor

Campos: id/version/source, read-only/idempotent/side-effecting/destructive, reversibility, filesystem scope, network egress, credential scope, timeout, expected output size, trust level, required environment e output schema.

## Lazy discovery

Não inserir centenas de schemas no prompt. Carregar inicialmente apenas catálogo resumido/capabilities; materializar schema completo quando a tarefa realmente o exigir.

## Side-effect journal

Antes de ação relevante registrar intent + idempotency key + target. Depois registrar outcome/provider receipt. Timeout com resultado ambíguo vira estado `unknown_side_effect`, não retry automático.

## MCP Governance

Todo MCP Server recebe identity, origin, version/provenance, trust, tools, permissions, allowed roots, network policy e secret scopes. MCP externo é untrusted por padrão até policy aprovar.

## Tool-output control

Cap por resposta, truncation consciente, summaries, artifacts e continuation tokens. Nunca despejar logs gigantes automaticamente no contexto.

## Policy examples

- read em root permitido: auto;
- write em arquivo do task scope: conforme agent permission;
- write fora do project root: deny por padrão;
- destructive/irreversible: approval/policy;
- credential-bearing network call: egress + secret policy.

## Evals

Medir wrong-tool selection, unnecessary calls, denied dangerous actions, duplicate side effects, schema-load overhead e tool-result token pressure.
