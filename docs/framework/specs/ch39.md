# Map contracts

Dependendo do gênero, map specs podem cobrir:

- intended routes;
- critical path;
- optional paths;
- landmarks;
- sightlines;
- cover/occlusion;
- encounter spaces;
- traversal types;
- spawn regions;
- objectives;
- resource distribution;
- safe zones;
- choke points;
- shortcuts;
- verticality;
- backtracking;
- streaming cells;
- navmesh connectivity.

# Automated spatial checks

- all required objectives reachable;
- spawn → objective reachability;
- no orphan regions;
- no unreachable collectibles obrigatórios;
- valid navmesh links;
- minimum clearances;
- forbidden overlap;
- spawn safety distances;
- line-of-sight rules;
- path length ranges;
- symmetry/fairness metrics quando design exige;
- streaming boundary traversal.

# Quantitative level evaluation

Pesquisa em avaliação genérica de níveis propõe conceitos mensuráveis como **area control, exploration e balance**. Esses conceitos podem inspirar metrics adapters, sem serem universais para todo gênero.

Fonte: [https://ojs.aaai.org/index.php/AIIDE/article/view/12680](https://ojs.aaai.org/index.php/AIIDE/article/view/12680)

# PCG

Para procedural generation, separar:

1. validity;
2. solvability;
3. diversity;
4. difficulty;
5. style/grammar adherence;
6. player-experience suitability.

Search-based PCG possui literatura consolidada sobre representação, fitness e search/optimization.

Fonte: [https://doi.org/10.1109/TCIAIG.2011.2148116](https://doi.org/10.1109/TCIAIG.2011.2148116)

# Critical warning

Métricas computacionais não substituem user studies. Estudo com níveis de Mario mostrou que métricas automáticas podem divergir da percepção dos jogadores.

Fonte: [https://ojs.aaai.org/index.php/AIIDE/article/view/12785](https://ojs.aaai.org/index.php/AIIDE/article/view/12785)

# PCG test protocol

Para seed corpus:

- generate N seeds;
- validate invariants;
- calculate distributions;
- identify outliers;
- run surrogate play agents;
- store failing seeds;
- promote real failures to regression corpus.

# Designer-assisted analysis

Atlas deve gerar heatmaps/artefatos derivados quando provider suportar:

- path density;
- deaths;
- damage;
- gaze/attention quando disponível;
- dwell time;
- resource pickups;
- encounters;
- AI stuck points;
- navigation failures;
- player backtracking.
