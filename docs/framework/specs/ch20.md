## Gemini CLI

A documentação oficial do repositório Gemini CLI descreve hooks síncronos em pontos como `SessionStart`, `SessionEnd`, `BeforeAgent`, `AfterAgent`, `BeforeModel`, `AfterModel` e seleção/tools, com possibilidade de adicionar contexto e bloquear ações. Extensions podem combinar custom commands, MCP, context, skills e hooks.

## Claude Code e Codex

O Atlas v0.3 já possui compilers/adapters para Claude Code e Codex. No v0.4, a prioridade não é simplesmente manter geração de arquivos: deve-se auditar as primitives oficiais atuais de cada harness e graduar enforcement pelo Connector Contract. A integração existente não deve ser assumida como full-native.

## Regra de manutenção desta pesquisa

Antes de cada connector milestone:

1. reabrir documentação oficial;
2. registrar host versions;
3. atualizar capability matrix;
4. criar fixture de compatibilidade;
5. só então declarar enforcement level.

<aside>
⚠️

Nunca prometer “bloqueio determinístico” ou “full native” baseado apenas em prompt/config. O nível divulgado deve corresponder às primitives realmente verificadas e cobertas pelo Connector Test Kit.

</aside>
