# Low-Fidelity Wireframing & Layout Prototyping Checklist

- [ ] Information hierarchy and primary content zones clearly defined
- [ ] Responsive breakpoints and column stacking behaviors specified
- [ ] Empty, error, loading, and success states wireframed alongside happy path
- [ ] Semantic landmarks (header, nav, main, footer) identified for accessibility
- [ ] Forms designed with visible labels, error regions, and logical tab order
- [ ] Whitespace balanced to prevent cognitive clutter and improve scannability
- [ ] Clear technical annotations provided for engineering layout implementation
