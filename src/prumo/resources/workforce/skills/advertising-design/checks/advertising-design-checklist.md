# Advertising Design Checklist

## AIDA Model
- [ ] **Attention:** Visual hook established within the first glance (bold typography, high contrast, or compelling imagery).
- [ ] **Interest:** Visual hierarchy clearly guides the user from the hook to the supporting information.
- [ ] **Desire:** Design incorporates emotional triggers (Pathos) or trust markers (Ethos).
- [ ] **Action:** CTA is visually dominant and unambiguously action-oriented.

## Layout & Composition
- [ ] Focal point is clear and singular.
- [ ] Elements are aligned to a defined grid.
- [ ] Directional cues (lines, gaze of models) point towards the primary message or CTA.
- [ ] Adequate active whitespace is used to reduce cognitive load.

## Call-to-Action (CTA)
- [ ] Contrast ratio against background is at least 4.5:1 (WCAG AA).
- [ ] Touch target (for mobile) is at least 44x44px.
- [ ] Placed in a logical position (typically bottom or right following Z/F patterns).
- [ ] Copy starts with a strong verb.

## A/B Testing Integrity
- [ ] Hypothesis is clearly stated (If [change], then [impact]).
- [ ] Only one variable is isolated for testing (e.g., Hero image A vs. Hero image B).

## Technical Requirements
- [ ] Design adheres to platform-specific aspect ratios.
- [ ] Safe zones are respected (no critical text near edges).
- [ ] Brand guidelines (colors, fonts, logos) are strictly followed.
