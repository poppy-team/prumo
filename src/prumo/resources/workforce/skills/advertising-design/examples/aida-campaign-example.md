# Example: SaaS Tool Retargeting Campaign

**Campaign Name:** ProTracker Q4 Retargeting
**Platform:** LinkedIn Sponsored Content (Single Image Ad)
**Dimensions:** 1200 x 627 (1.91:1)

## 1. Goal & Audience
- **Primary Objective:** Free trial signups.
- **Target Audience:** Mid-level project managers who visited the pricing page but did not convert.

## 2. AIDA Mapping
- **Attention (Hook):** Headline: "Still managing projects in spreadsheets?" (Bold, sans-serif, high contrast dark blue on light gray).
- **Interest (Value Prop):** Subheadline: "Save 10+ hours a week with automated workflows."
- **Desire (Emotional/Logic Trigger):** Hero image: A relaxed, smiling professional looking directly at the camera, next to a clean, abstracted dashboard graphic showing a 100% completion bar.
- **Action (CTA):** "Start Free 14-Day Trial". Button is bright Orange (#FF5722) against a navy background.

## 3. Visual Persuasion
- **Ethos (Trust):** 5-star rating graphic below the CTA.
- **Pathos (Emotion):** Relief and control depicted in the model's expression.
- **Logos (Logic):** The specific metric "10+ hours" provides logical justification.

## 4. Composition Details
- **Layout:** Z-pattern. Headline top left -> Image top right -> Subhead bottom left -> CTA bottom right.
- **Whitespace:** Ample padding (minimum 40px) around the text block to separate it from the imagery.

## 5. A/B Testing Plan
- **Control (A):** The design as described above (Smiling Professional).
- **Variant (B):** Everything identical, but the Hero image is replaced with a high-fidelity software UI mockup.
- **Hypothesis:** If we show the software UI (Variant B) instead of a person (Control A), then we expect click-through rates to increase because this audience (retargeting) is already aware of the problem and wants to see the specific solution interface.
