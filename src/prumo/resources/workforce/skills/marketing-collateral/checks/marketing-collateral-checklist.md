# Marketing Collateral Checklist

## Digital Assets (General)
- [ ] Asset aligns with the designated marketing funnel stage.
- [ ] Correct color profile (RGB/sRGB) is used.
- [ ] File names follow standard DAM naming conventions.

## Social Media
- [ ] Dimensions match platform specs (e.g., IG: 1080x1080/1080x1920, FB: 1200x630, X: 1200x675, LI: 1200x627).
- [ ] Text-to-image ratio is appropriate for the platform.
- [ ] Brand logos and elements have sufficient clear space.

## Email Marketing
- [ ] Max width is 600px.
- [ ] CSS is inline.
- [ ] Dark mode compatibility tested.
- [ ] All images have descriptive alt text.
- [ ] Primary CTA is clearly visible above the fold.

## Landing Pages
- [ ] Above-the-fold hero section is compelling.
- [ ] Social proof/testimonials are present.
- [ ] Feature benefits are clearly outlined.
- [ ] FAQ section addresses common objections.
- [ ] Final CTA is strong and distinct.

## Print Materials
- [ ] Document is in CMYK color mode.
- [ ] 3mm bleed area is included on all sides.
- [ ] All raster images are at least 300 DPI at 100% scale.
- [ ] Fonts are outlined or embedded.
- [ ] Exported as PDF/X-1a standard.
