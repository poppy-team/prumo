# Example: Social Media Campaign Collateral

**Context:** Product launch for a new SaaS feature (Awareness phase).

## Selected Formats
1. **Instagram Carousel** (1080x1080px, 4 slides)
   - Slide 1: Hook ("Struggling with manual reporting?")
   - Slide 2: Agitate ("You lose 5 hours a week to spreadsheets.")
   - Slide 3: Solution ("Automate it in 2 clicks with [Feature].")
   - Slide 4: CTA ("Try it free. Link in bio.")
2. **LinkedIn Single Image** (1200x627px)
   - Professional graphic highlighting the time-saving metric (e.g., "Save 5 hours/week").
3. **Twitter/X Graphic** (1200x675px)
   - Bold, high-contrast illustration of the dashboard.

## Technical Execution
- Built in Figma using the '2026 Brand System' library.
- Exported as 2x PNGs for maximum crispness on retina displays.
- Uploaded to DAM as `20260927_FeatureLaunch_IGCarousel_1080x1080_v1.zip` etc.
