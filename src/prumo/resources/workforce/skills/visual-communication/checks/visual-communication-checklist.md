# Visual Communication Checklist

## 1. Visual Hierarchy
- [ ] Primary, secondary, and tertiary information levels are clearly defined.
- [ ] Size and scale are used effectively to denote importance.
- [ ] Color contrast draws attention to primary actions and data points.
- [ ] Whitespace is used intentionally to separate unrelated elements and emphasize key content.
- [ ] Proximity accurately reflects semantic relationships (Gestalt).
- [ ] Typographic weights are applied systematically to support scanning.

## 2. Semiotics & Iconography
- [ ] All icons have a clear and unambiguous signifier-signified relationship.
- [ ] Symbols rely on established conventions for the target audience.
- [ ] Cultural connotations of colors and imagery have been validated for the primary demographic.
- [ ] Icons are accompanied by text labels where the symbol alone might be ambiguous.

## 3. Visual Rhetoric
- [ ] The visual design supports the intended emotional response (Pathos).
- [ ] The professionalism and consistency of the design establish trust (Ethos).
- [ ] The structure and layout logically guide the user through the content (Logos).

## 4. Information Design & Data Visualization
- [ ] Non-data ink is minimized (no 3D effects on 2D data, subtle gridlines).
- [ ] The Lie Factor of all visualizations is $\approx 1.0$ (no visual distortion of data).
- [ ] Small multiples or sparklines are utilized effectively for complex comparisons.
- [ ] Data is labeled directly where possible, minimizing the need for disconnected legends.

## 5. Accessibility & Strategy
- [ ] Information is not conveyed by color alone.
- [ ] Contrast ratios meet minimum WCAG requirements (e.g., $\ge 4.5:1$ for normal text).
- [ ] The design accounts for typical scanning patterns (e.g., F-pattern or Z-pattern).
- [ ] Progressive disclosure is used to manage cognitive load in complex interfaces.
