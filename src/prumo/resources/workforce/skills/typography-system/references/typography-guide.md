# Typography Guide & References

## Key Concepts
1. **Modular Scales:** Mathematical progression of font sizes (e.g., Minor Second 1.067, Major Third 1.25, Golden Ratio 1.618).
2. **Fluid Typography:** Using CSS `clamp()` to scale typography linearly between min and max viewports.
3. **Variable Fonts:** A single binary delivering multiple variations (weight, width, slant) using axes (e.g., `wght`, `wdth`).
4. **OpenType Features:** Advanced typographic controls like `liga` (ligatures), `tnum` (tabular numbers), `onum` (old-style numerals), `smcp` (small caps).

## Authoritative References
- **Tim Brown's Modular Scale:** Principles for mathematical type scaling.
- **Robert Bringhurst:** "The Elements of Typographic Style" - Foundational typographic theory.
- **Material Design Type System:** Guidelines for component-level typography.
- **Apple HIG Typography:** Best practices for legibility and dynamic type.
- **Google Fonts Variable Font API:** Documentation on variable axis configuration.
- **W3C WCAG 2.1:** Accessibility requirements for text contrast and resizeability.
