# Design Critique Checklist

## Context Setting
- [ ] Problem statement and user goals are clearly understood.
- [ ] Scope of feedback is explicitly defined.
- [ ] Target audience is identified.

## Evaluation Criteria Checked
- [ ] Usability (ease of use, intuitive flows).
- [ ] Strategic alignment (meets business goals).
- [ ] Brand consistency (follows design system).
- [ ] Visual quality (hierarchy, contrast, typography).
- [ ] Accessibility (WCAG compliance, color contrast, screen reader logic).
- [ ] Technical feasibility (can be built within constraints).
- [ ] Content clarity (copy is clear, concise, and appropriate).

## Feedback Framing
- [ ] Feedback focuses on the work, not the creator.
- [ ] Uses 'I notice...', 'I wonder...', 'What if...' framing.
- [ ] Issues are assigned a severity rating (1-Cosmetic, 2-Minor, 3-Major, 4-Catastrophe).
- [ ] Feedback is actionable.

## Documentation
- [ ] Critique report or decision log is populated.
- [ ] Trade-offs and alternatives considered are documented.
