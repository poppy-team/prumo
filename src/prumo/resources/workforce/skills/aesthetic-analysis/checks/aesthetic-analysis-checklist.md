# Aesthetic Analysis Checklist

## Pre-Evaluation Readiness
- [ ] Brand guidelines and core values are documented and understood.
- [ ] Target user demographics and accessibility requirements are defined.
- [ ] The aesthetic movement(s) to be evaluated are clearly identified.

## Historical & Visual Analysis
- [ ] The historical origins of the aesthetic (e.g., Bauhaus, Swiss Design, Modernism) have been traced.
- [ ] Core visual characteristics (typography, color, spacing, depth, texture) are mapped out.
- [ ] Common CSS/technical implementation patterns are identified.

## Accessibility Assessment
- [ ] Color palettes have been tested for WCAG contrast compliance.
- [ ] Visual hierarchy and cognitive load implications have been evaluated.
- [ ] Risks associated with the aesthetic (e.g., low contrast in Neumorphism, legibility in Glassmorphism) are documented with mitigation strategies.

## Brand Alignment & Strategy
- [ ] Brand Alignment Score has been calculated based on cultural and psychological associations.
- [ ] The aesthetic's current position in the Trend Lifecycle is identified (Emergence, Peak, Mainstream, Decline, Revival).
- [ ] Technical implementation complexity and performance impact have been estimated.

## Final Review
- [ ] The evaluation template is fully populated.
- [ ] Concrete recommendations (adopt, adapt, or reject) are provided.
- [ ] Fallback strategies for performance or accessibility constraints are defined.
