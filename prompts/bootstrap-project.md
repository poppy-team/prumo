- use Markdown + JSON canonical formats;
- explicitly obtain/record the project model roster;
- generate `prumo.json`, `PROJECT_STATE.md`, `docs/PRUMO.md`, JSON Goals/manifests and Project Intelligence seed;
- select the smallest useful workforce;
- enable Lean Progressive Context with bounded input/output and depth <= 1;
- do not create LLM-only duplicate documentation;
- validate the result.
